# Хроники Дымки

Статический мастерский генератор случайных событий для кампании в Драккенхейме. Выбирает событие по таблице района, показывает выпавшее значение и диапазон, добавляет описание сцены, искривлённые руины и удачную находку. Ссылки на существ ведут прямо к соответствующим статблокам.

## Локальный запуск

Сайт не требует сборки. Откройте `index.html` напрямую или запустите любой статический сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Проверка таблиц и механики бросков:

```bash
npm test
```

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и каталог `/ (root)`. Все файлы уже используют относительные пути и работают без серверной части.
